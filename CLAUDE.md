# Clogem

The CLI and npm package are in `npm-cli/`. Read [npm-cli/CLAUDE.md](npm-cli/CLAUDE.md) for how to build, test, and commit that package.

The website is a separate private repository, checked out at `web/`: [surya-shreevathsa11/clogem-web](https://github.com/surya-shreevathsa11/clogem-web).

They are one product. A shared behavior is not finished until both places implement it. The list is [npm-cli/docs/same-product.md](npm-cli/docs/same-product.md) and `web/SAME.md`. Change both copies together.
